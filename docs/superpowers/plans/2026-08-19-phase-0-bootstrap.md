# FideliChem Phase 0 Bootstrap Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the installable, domain-free FideliChem application shell with a versioned CLI, a PySide6 window, idempotent operational logging, locked dependencies, and verified Windows/Ubuntu automation.

**Architecture:** Keep the Phase 0 package intentionally small: package metadata owns the version, the CLI and GUI are separate entry points, logging is an application-boundary service, and the Qt window contains no scientific or persistence logic. Every behavioral module is introduced through RED-GREEN-REFACTOR; repository automation and agent configuration are verified separately as configuration artifacts.

**Tech Stack:** Python 3.12, uv 0.11+, Hatchling, PySide6 6.x, argparse, pytest, pytest-qt, pytest-cov/coverage, Ruff, mypy, pip-audit, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-08-19-phase-0-bootstrap-design.md`

## Global Constraints

- Support exactly Python `>=3.12,<3.13` in Phase 0.
- Keep PySide6 as the only runtime dependency, constrained to `PySide6>=6.8,<7`.
- Do not introduce RDKit, Pydantic, SQLAlchemy, Alembic, NumPy, SciPy, pandas, Polars, PyQtGraph, Matplotlib, PyInstaller, database schemas, adapters, or scientific domain models.
- Follow strict RED-GREEN-REFACTOR for every production behavior; observe the expected failure before adding its implementation.
- Measure branch coverage and fail the suite below 80%.
- Keep CLI, Qt, and logging modules independent of future scientific layers.
- Test Qt with `QT_QPA_PLATFORM=offscreen`, event-aware waits, explicit cleanup, and bounded subprocess timeouts; never use arbitrary sleeps or pixel comparisons.
- Run CI on `windows-latest` and `ubuntu-latest` with Python 3.12 and the committed `uv.lock`.
- Never add secrets, telemetry, network services, `eval`, pickle, imported-file execution, or publishing/release side effects.
- Preserve the product plan as the source of truth; Phase 1 must not begin as part of this plan.
- Do not invent a project license in Phase 0.

```python
import logging

_LOGGER_NAME = "fidelichem"
_HANDLER_NAME = "fidelichem.console"
_FORMAT = "%(asctime)s %(levelname)s %(name)s: %(message)s"


def _resolve_level(level: int | str) -> int:
    if isinstance(level, int):
        return level

    resolved = logging.getLevelNamesMapping().get(level.upper())
    if resolved is None:
        raise ValueError(f"Unknown logging level: {level}")
    return resolved


def configure_logging(level: int | str = logging.INFO) -> logging.Logger:
    resolved_level = _resolve_level(level)
    logger = logging.getLogger(_LOGGER_NAME)
    owned_handlers = tuple(
        handler
        for handler in logger.handlers
        if handler.get_name() == _HANDLER_NAME
    )

    if owned_handlers:
        handler = owned_handlers[0]
        for duplicate in owned_handlers[1:]:
            logger.removeHandler(duplicate)
            duplicate.close()
    else:
        handler = logging.StreamHandler()
        handler.set_name(_HANDLER_NAME)
        handler.setFormatter(logging.Formatter(_FORMAT))
        logger.addHandler(handler)

    handler.setLevel(resolved_level)
    logger.setLevel(resolved_level)
    logger.propagate = False
    return logger
```

The mutations in this function are confined to the standard-library logging boundary; application data remains immutable.

import sys
from collections.abc import Sequence

from PySide6.QtWidgets import QApplication

from fidelichem.app.logging import configure_logging
from fidelichem.gui.main_window import MainWindow


def create_application(argv: Sequence[str] | None = None) -> QApplication:
    existing = QApplication.instance()
    if existing is None:
        arguments = list(argv) if argv is not None else list(sys.argv)
        return QApplication(arguments)
    if not isinstance(existing, QApplication):
        raise RuntimeError("An incompatible Qt core application already exists")
    return existing


def main(argv: Sequence[str] | None = None) -> int:
    logger = configure_logging()
    application = create_application(argv)
    window = MainWindow()
    window.show()
    logger.info("FideliChem application started")
    exit_code = application.exec()
    logger.info("FideliChem application stopped with exit code %s", exit_code)
    return exit_code
```

# ADR 0000: Phase 0 bootstrap toolchain

- Status: Accepted
- Date: 2026-08-19

## Context

FideliChem needs a reproducible Windows and Ubuntu desktop bootstrap before any
scientific domain or storage decisions are implemented.

## Decision

Use Python 3.12, uv with a committed lockfile, Hatchling as the build backend,
PySide6 as the only runtime dependency, and pytest-based tests with 80% minimum
branch coverage. Defer all scientific dependencies and PyInstaller packaging to
the phases that first need them.

## Consequences

The initial compatibility surface stays small and CI can validate the real CLI
and Qt shell on both target operating systems. Python 3.12 compatibility with
the future chemistry stack must be rechecked before Phase 2; changing the Python
minor then requires an explicit ADR and lockfile regeneration.
```
